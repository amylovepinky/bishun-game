# 筆順小畫家

給小朋友用手指練習基本筆畫、常用部首和國字筆順的手機網頁遊戲。

- **闖關冒險**：家長自訂關卡名稱和每一關的生字（例如照課文），孩子在冒險地圖上一關一關解鎖，過關得到動物貼紙
- **家長設定**：有家長鎖；可新增、編輯、排序、刪除關卡，可選嚴格模式，並可複製備份文字到別支手機還原
- **基本筆畫**：14 種（橫、豎、撇、捺、點、提、豎鉤…）
- **部首樂園**：20 個常用部首，每關先寫部首，再寫同部首的字
- **自由練習**：教育部常用國字 4,847 字都能練
- 每個字三步：看筆順動畫 → 描描看 → 自己寫；每一筆都即時檢查順序、方向和整齊度

## 檔案

| 路徑 | 說明 |
| --- | --- |
| `index.html` | 遊戲本體（可直接用瀏覽器開，需搭配 `d/`） |
| `d/s0.json` … `d/s31.json` | 筆順資料（依字碼分成 32 份，自由練習時才下載） |
| `src.html` | 原始碼（尚未嵌入課程用字的資料） |
| `tools/conv.py` | 把 zh-stroke-data 轉成 `d/` 的精簡格式 |
| `tools/build.py` | 把課程用字的資料嵌入 `src.html`，產生頁面內容 |

`index.html` 需要經由網頁伺服器開啟（例如 GitHub Pages），直接用檔案開啟時「自由練習」會讀不到 `d/` 的資料。

## 資料來源與授權

筆順資料來自 [g0v/zh-stroke-data](https://github.com/g0v/zh-stroke-data)，內容為教育部《常用國字標準字體筆順》。
依該專案說明，這份筆順資料是依著作權法第 50 條，在**非營利的教育目的**下合理使用，**不可用於商業用途**。
若要做成付費或營利的 App，需要改用其他資料來源，或向教育部取得授權。
